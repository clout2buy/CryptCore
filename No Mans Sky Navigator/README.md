# No Man's Sky Navigator

This is our running tracker for your No Man's Sky discoveries, stations, missions, routes, and useful notes.

## How we'll use this

Whenever you tell me something like:

- "I found a space station with an S-class scanner module"
- "This system is near an Atlas Station"
- "This planet has copper and aggressive sentinels"
- "This trade terminal sells wiring looms"
- "I'm trying to get back to this place later"

I'll update the tracker so you have a clean map of where things are and what to do next.

## Main files

- `locations.md` - systems, space stations, planets, bases, portals, and landmarks
- `missions.md` - current objectives like Atlas Path and next steps
- `resources.md` - useful planets, materials, shops, upgrades, and economies
- `route-log.md` - where you've been and where you're heading next
- `index.html` - visual dashboard you can open in a browser
